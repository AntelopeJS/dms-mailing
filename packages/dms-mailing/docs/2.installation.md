# Installation

The Mailing module runs inside a project that loads `@antelopejs/dms` 0.7.21 or later, a database module and a module implementing `@antelopejs/interface-email`.

::steps
### Add the module

```bash [Terminal]
ajs project modules add @antelopejs/dms-mailing
```

### Add an e-mail provider

The module hands every e-mail to the `@antelopejs/interface-email` implementation of the project. With nodemailer:

```bash [Terminal]
ajs project modules add @antelopejs/nodemailer
```

```typescript [antelope.config.ts]
export default defineConfig({
  name: "my-project",
  modules: {
    "dms-mailing": {
      source: { type: "package", package: "@antelopejs/dms-mailing", version: "^0.4.0" },
      config: {},
    },
    nodemailer: {
      source: { type: "package", package: "@antelopejs/nodemailer", version: ">=0.0.5 <1.0.0" },
      config: {
        host: "smtp.example.com",
        port: 587,
        auth: { user: "apikey", pass: process.env.SMTP_PASSWORD },
        defaults: { from: "hello@example.com" },
      },
    },
    // dms, api, mongodb, auth-jwt, file-storage-local, ...
  },
});
```

Use `config: { ethereal: true }` in development to send to a throwaway Ethereal inbox.

### Set the public origin

The webhook URL and the logo in e-mails use the DMS `clientBaseUrl`, the public origin of the dashboard. Set it in the `dms` module's config before a real provider has to reach the webhook.

### Open the module

Restart the backend and the frontend. The module appears under **Modules › Mailing**, at `/modules/mailing/overview`. Until a provider and a template exist, the overview shows a setup checklist.
::

::tip
Create your first template from a starter: **Order confirmation**, **Shipping update**, **Password reset** and **Invoice available** come with English and French content, variables and test data.
::

## Try it in the playground

```bash [Terminal]
pnpm install
pnpm --dir frontend-vue install
pnpm --dir playground install
pnpm dev            # backend on http://localhost:5010
pnpm frontend:dev   # dashboard on http://localhost:3001
```

Run these in `packages/dms-mailing`. The playground uses MongoDB at `mongodb://localhost:27017` (set `MONGO_URL` to change it) and sends to Ethereal, or to a local SMTP server when `SMTP_PORT` is set.
